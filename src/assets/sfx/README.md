# Sound effects

All of these are public domain (CC0): free to use in any project, with no
credit required. They were trimmed, made mono and level-matched, and saved as
small MP3s.

- Kenney (kenney.nl), via OpenGameArt: Casino Audio, Interface Sounds,
  RPG Audio and Music Jingles.
- HaelDB, via OpenGameArt: Card Game Sounds (`domino-pass`).

Each game uses its own set (see `THEMES` in `src/lib/audio.tsx`).
